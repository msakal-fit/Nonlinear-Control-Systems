# Shared functions

These functions are used by more than one homework. Add this folder and the homework folder to the MATLAB path before running an exercise.

| File | Used by | Purpose |
| --- | --- | --- |
| `RK4.p` | Hw02, Hw03, Hw04 | Numerical integration |
| `animate_quadcopter.p` | Hw02, Hw03, Hw04 | Trajectory and attitude animation |
| `fbl_tracking_r_u.m` | Hw02, Hw03, Hw04 | Feedback-linearizing translation controller |
| `angles_from_force.p` | Hw03, Hw04 | Desired attitude from force and yaw |
| `compute_error_states_and_derivatives.p` | Hw03, Hw04 | Attitude error states and derivatives |
| `euler_rates_zyx.m` | Hw03, Hw04 | Body angular velocity to Euler-angle rates |
